推荐方案（主推）

- 前端 ：Vue 3 + TypeScript + Vite
- 后端 ：FastAPI（Python）+ SQLAlchemy
- 数据库 ：SQLite
- 图表 ：Apache ECharts（折线图/雷达图/散点图都很成熟）
- 拖拽 ：SortableJS（或 vue-draggable-plus）
- 导出图片 ：html2canvas
- CSV 解析 ：后端用 pandas，前端可选 PapaParse（做预览时用）
  前端栈细化
- UI 组件库 ：Element Plus（中文资料多，开发快）
- 状态管理 ：Pinia
- 路由 ：Vue Router
- 网络请求 ：Axios
- 本地持久化 ：pinia-plugin-persistedstate（或自己封装 localStorage）
- 样式美化 ：Tailwind CSS（可选，做“更美观”很方便）
  后端栈细化
- 接口框架 ：FastAPI（自动接口文档，调试方便）
- ORM ：SQLAlchemy
- 数据校验 ：Pydantic
- 迁移工具 ：Alembic
- CSV 分析 ：pandas（后续出勤算法、团队/小队统计都适合）
